# AI to Agent 六小時課程藍圖

> 以五大 5-Star Labs 為外部知識雷達，以 Verify／VAD／VAC 為教材轉化主線。

## 課程目標

學員完成課程後，能夠：

1. 分辨 Chat、Workflow 與 Agent。
2. 從五大 Labs 找到可信的 Agent 學習與實作資源。
3. 依任務難度、風險與成本選擇模型與工具。
4. 用 VAD 描述需求、流程、輸出與驗收。
5. 將成功任務封裝成可重用 VAC。
6. 完成一個可展示、可測試的 AI to Agent 小專案。

## 驗收量表

| 指標 | 權重 | 判斷方式 |
|---|---:|---|
| 任務完成率 | 20% | 是否符合指定輸出與必要條件 |
| 正確性 | 20% | 事實、流程與資料是否可驗證 |
| 可重現性 | 15% | 他人依 VAC 是否能再次完成 |
| 成本效率 | 15% | 時間、Token、API 與人工修正成本 |
| VAD 清晰度 | 10% | 非專業者能否看懂任務流程 |
| 跨模型一致性 | 10% | 不同模型輸出是否維持核心標準 |
| 風險控制 | 10% | 是否有人工核准、權限與失敗修復設計 |

## 教學者提醒

- 不以「成功跑出 Demo」當作唯一成果。
- 要求學員記錄失敗，因為失敗是 Verify 與 VAC 的原料。
- 同一 VAC 至少交給兩個模型或 Agent 測試。
- 對高風險與不可逆任務保留人工決策權。
- 工具教學要回到企業價值：增效提速、降低學習曲線、降低錯誤與人工成本。
