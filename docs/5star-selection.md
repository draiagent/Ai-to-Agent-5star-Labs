# 五星 Labs 評選與退出機制

> AI Coach 益力康陳董｜2026 AI to Agent

## 目的

五星評選的目的不是製造排名，而是確保進入正式教材的來源具備存在性、活躍度、Agent 關聯、教材價值、可驗證性與互補性。

## 評分表

每項 0–5 分，總分 30 分；建議 **25 分以上**且沒有任何必要條件不合格，才能列為 5-Star Lab。

| 構面 | 5 分 | 3 分 | 0–1 分 |
|---|---|---|---|
| 存在性 | 官方入口穩定且公開 | 部分內容需帳號 | 無法確認或只有二手資料 |
| 活躍度 | 近 3 個月持續更新 | 近 6 個月有更新 | 超過 6 個月無實質更新 |
| Agent 關聯 | Agent 為核心主題 | Agent 為重要分支 | 僅泛 AI 新聞或 Prompt 內容 |
| 教材價值 | 原理、範例、任務與討論完整 | 可形成單一教案 | 難以轉成可教內容 |
| 可驗證性 | 有版本、原始碼、文件或原始討論 | 部分可追溯 | 來源不明或不可重現 |
| 互補性 | 扮演不可取代角色 | 與其他 Lab 部分重疊 | 高度重複且無新增價值 |

## 必要條件

- 有可公開驗證的官方入口。
- 與 Agent、Skills、MCP、Tool Use、Workflow、Memory、A2A 或 Evaluation 高度相關。
- 可以被轉化為公開教學、課程教材或實驗任務。
- 不以付費推廣或單次話題作為五星依據。

## 每季複核

1. 檢查官方入口與主要教材連結。
2. 記錄最近一次 Release、Commit、課程更新或社群討論日期。
3. 抽樣一個內容進行最小可行實驗。
4. 評估授權與引用條件是否改變。
5. 更新總分與觀察備註。

## 降級與退出

符合以下任一情況，先標示為「觀察中」：

- 超過六個月沒有可辨識的實質更新。
- 官方入口長期失效。
- 主題明顯偏離 AI to Agent。
- 內容大量不可驗證、不可重現或含高風險做法。
- 教材授權改變，無法合理引用或改作。

觀察一季後仍未改善，即移出 5-Star 清單，但保留歷史紀錄，避免把「退出」誤解為平台不存在。

## 新平台觀察名單

重要但尚未符合五星條件的平台，可先列入 Watchlist。例如 Cursor Origin 雖具 Agent-native Repository 的戰略意義，但目前仍在 Early Beta，且官方建立流程僅提供 Internal／Private Repo，因此暫不取代 GitHub 作為公開教材 Lab。

Watchlist 每月記錄一次重大更新，每季依同一張評分表決定升級、續留或移除，避免因新聞熱度直接改變正式清單。

## 引用原則

- 優先引用官方文件、原始 Repo、Release 與原始討論。
- 摘要必須改寫並附連結，不大段複製原文。
- 程式與圖片依原專案 License 使用。
- 記錄查核日期，避免把舊資訊當作現況。
- 針對社群發言，區分個人經驗、社群共識與已驗證事實。
